# 将棋実況エディタ

ボイロ将棋実況のための動画編集ソフトです。
台本・音声・対局の録画を入れると、字幕・立ち絵・口パクまで付いた動画を組み立てます。
表情や矢印、継ぎ盤、セリフと局面の合わせ方は、Claude Desktop に頼めます。

> ボイロ将棋実況に特化して作っています。そのほかの使い方は想定していません。

## ダウンロード

[Releases（最新版）](../../releases/latest) から `ai-memo-editor-…zip` をダウンロードしてください。
GitHub のアカウントは要りません。

## 起動のしかた

1. zip を解凍する
2. Windows は `start-windows.bat`、Mac は `start-mac.command` をダブルクリック
3. ブラウザでエディタが開きます。黒い画面は、使っている間は閉じないでください

「Node.js が入っていない」と出たら、[Node.js](https://nodejs.org/ja) の LTS 版を入れてから、もう一度ダブルクリックしてください。

## Claude Desktop をつなぐ

1. [Claude Desktop](https://claude.ai/download) を入れる
2. 設定 → 拡張機能 を開き、解凍したフォルダの中の `将棋実況エディタ.mcpb` をドラッグして入れる
3. エディタを開いたまま、右の「AI」タブの言葉をコピーして Claude Desktop に貼って送る

## 使い方の流れ

① 素材 → ② 配置 → ③ 演出・修正 → ④ 書き出し

- **素材**：録画・棋譜・台本・立ち絵（PSD）・音声を全部まとめて入れます
- **台本**：行の頭に「話者の名前：」を付けます（例：`六花：今日は将棋クエスト！`）。（ ）の中はメモで、字幕にも読み上げにも入りません
- **音声**：VOICEPEAK を使う場合は、エディタが作る SSML ファイルで読み込むと、符号（23歩 など）が正しく読まれます。書き出した音声は、話者ごとのフォルダのまま素材に入れてください
- **将棋GUIの画像**：盤面の画像をコピーして、③ の画面で Ctrl+V すると、いまのセリフに画像が付きます

## アップデート

新しい zip をダウンロードして、`update.bat` をダブルクリックしてください（zip は update.bat の隣かダウンロードフォルダに置きます）。
作った動画のデータ（my-project）は消えません。
